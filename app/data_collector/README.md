# 🔍 Data Collector

Модуль **Data Collector** является первым компонентом пайплайна системы мониторинга и анализа уязвимостей в зависимостях Python-проектов.

Он отвечает за извлечение первичной информации о зависимостях из проекта, используя только стандартную библиотеку `importlib.metadata`.

Для корректной работы необходимо наличие виртуального окружения в проекте, из которого необходимо извлечь информацию о зависимостях.
Подразумевается использование данного модуля в CI, например в github.

Однако ниже представлен вариант для локального тестирования.
## 🚀 Быстрый старт
### ❗ Важно
Для корректной работы нужно иметь папку в своем проекте ``.venv`` или ``venv``

### 1. Подготовить модуль data_collector
скопируйте модуль app/data_collector в свой проект следующей командой

```shell
cp app/data_collector your_project
```
где
```markdown
app/data_collector - путь до модуля data_collector
your_project - корневая директория вашего проекта
```

### 2. Запуск data_collector 

```shell
python main.py
```
На выходе вы получите ``dependencies.json``
