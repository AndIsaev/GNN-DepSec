# Генератор синтетических проектов (generate_fake_projects.py)

Создаёт набор виртуальных Python-проектов с файлами `requirements.txt`, в которых зависимости подобраны из двух пулов:
- **VULNERABLE_POOL** — версии пакетов с известными уязвимостями (CVE);
- **SAFE_POOL** — современные безопасные версии тех же пакетов.

Генерация воспроизводима: seed для каждого проекта фиксируется его порядковым номером, поэтому при повторном запуске получится точно такой же набор зависимостей.

## Использование

```bash
python generate_fake_projects.py [опции]
```
## Опции командной строки
```markdown
Аргумент	Тип	По умолчанию	Описание
--critical	int	10	Число проектов только с уязвимыми зависимостями
--mixed	int	20	Число проектов со смесью уязвимых и безопасных зависимостей
--safe	int	70	Число проектов только с безопасными зависимостями
--min-deps	int	5	Минимальное количество зависимостей в проекте (фактическое — от min_deps до min_deps+5)
--output-dir	Path	datasets/fake_projects	Директория для сохранения проектов
--seed	int	None	Глобальный seed для перемешивания категорий (если не задан — случайный порядок)
```
## Примеры
Сгенерировать стандартный набор (10+20+70 проектов):

```shell
python generate_fake_projects.py
```
Создать 5 критических, 10 смешанных и 30 безопасных проектов, минимум 7 зависимостей:

```shell
python generate_fake_projects.py --critical 5 --mixed 10 --safe 30 --min-deps 7
```
Указать другую выходную папку:

```shell
python generate_fake_projects.py --output-dir my_fake_projects
```
## Структура выходных данных
После выполнения скрипта создаётся директория с подпапками project_000, project_001, … В каждой — файл requirements.txt.
Пример содержимого:
```text
requests==2.22.0
urllib3==1.25.11
django==3.2.0
...
```
